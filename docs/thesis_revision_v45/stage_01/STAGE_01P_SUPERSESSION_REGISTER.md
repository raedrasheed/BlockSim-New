# Stage 1P — Supersession Register

Stage 1P supersedes specific Stage-1O statements by RECORDING the supersession here and updating ONLY the
un-suffixed normative documents (`STAGE_01_*.md` / `STAGE_01_*.csv`). Historical Stage-1A…1O lettered
artifacts (`STAGE_01A_*`…`STAGE_01O_*`) are NOT modified — a superseded statement may still appear verbatim in
a frozen lettered artifact as a historical record. Name remains **PoCol**; mechanism is **the idle policy
within PoCol**; the A1 baseline (`8.420833333 kWh`) is unchanged.
