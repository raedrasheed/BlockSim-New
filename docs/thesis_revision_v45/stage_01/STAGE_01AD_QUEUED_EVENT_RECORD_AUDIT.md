# Stage 1AD — Central Queued-Event Record & Registry Audit (correction AD1)

This is a documentation-only audit of correction **AD1** — the central `queued_event_record` + `queued_event_registry`
as the single authoritative queue-status source — in the Stage-1 formal specification of **PoCol** and the idle policy
within PoCol. It was generated AFTER the normative documents (`STAGE_01_PROTOCOL_PSEUDOCODE.md`,
`STAGE_01_ROUND_STATE_MACHINE.md` §3.10h, `STAGE_01_TERMINOLOGY.md` Stage-1AD addendum,
`STAGE_01_INVARIANT_CATALOGUE.md` I16 Stage-1AD clause) and the Stage-1AD semantic test vectors
(`STAGE_01AD_SEMANTIC_TEST_VECTORS.md`, TV252–TV261) were final; it modifies no specification document and quotes the
current lines of the frozen source of truth. The A1 baseline `8.420833333 kWh` is unchanged and the binding PoCol naming
rule (the algorithm is **PoCol**; the mechanism under audit is the idle policy within PoCol) is preserved. Every claim
below is grounded in an actual quote from `STAGE_01_PROTOCOL_PSEUDOCODE.md` (the primary source) with an approximate line
anchor, and is corroborated by the relevant Stage-1AD test vector.

## Result

**PASS** — AD1 is faithfully and internally consistently specified in `STAGE_01_PROTOCOL_PSEUDOCODE.md`. The
`STRUCTURE queued_event_record` declares exactly `(event_ref : EventRef immutable, event_type, dispatch_envelope :
immutable complete ordinary-event envelope, immutable_payload, queue_status : EventQueueStatus)` (~L494–L502);
`queued_event_registry : map EventRef -> queued_event_record` is declared the ONE authoritative queue-status source
(~L504, ~L1763–L1767); the `EventQueueStatus` transition table is exactly `QUEUED → {DISPATCHING, CANCELLED}`,
`DISPATCHING → CONSUMED`, with `CONSUMED`/`CANCELLED` terminal (~L506–L510); a `setup_retry_record` keeps only its
immutable `seat_event_ref` (+ `status : SetupRetryStatus` and non-queue lifecycle fields) with its queue state read as
`queued_event_registry[seat_event_ref].queue_status` (~L511–L513, ~L1752–L1756); the AC8 per-record `event_queue_status`
field is removed, with all nine residual `event_queue_status` mentions confirmed to be removal/relocation/history
comments rather than a live writable field (Check 5); `RunInitialise` initialises `queued_event_registry` to an empty map
and the `setup_retry_records` description no longer lists `event_queue_status` (~L1790–L1791, ~L1752–L1756); and both
retry seating sites publish `setup_retry_record` without an `event_queue_status` field (~L2093–L2096, ~L5528–L5531). The
pseudocode, RSM §3.10h, terminology addendum, invariant I16 Stage-1AD clause, and TV252 (with TV255/TV260 corroboration)
are mutually consistent. No inconsistency and no residual live `event_queue_status` write on `setup_retry_record` was
found. The A1 baseline `8.420833333 kWh` and the binding PoCol naming rule are preserved.
