# Stage 1T — Supersession Register

Stage 1T supersedes specific Stage-1S (and earlier) statements by RECORDING the supersession here and updating
ONLY the un-suffixed normative documents (`STAGE_01_*.md` / `STAGE_01_*.csv`). Historical Stage-1A…1S lettered
artifacts (`STAGE_01A_*`…`STAGE_01S_*`) are NOT modified — a superseded statement may still appear verbatim in a
frozen lettered artifact (and in a prior stage's terminology/traceability addendum) as a historical record. Name
remains **PoCol**; the mechanism is **the idle policy within PoCol**; the A1 baseline (`8.420833333 kWh`) is
unchanged.
